# 🍰 Bolos Da Ma — Bolos Artesanais

Landing page responsiva para uma loja de bolos artesanais, inspirada na referência visual fornecida.

## 📱 Sobre o projeto

O site foi desenvolvido com foco em celulares, mas também se adapta a tablets e computadores.

A proposta é apresentar os produtos de forma visual e facilitar o contato do cliente pelo WhatsApp.
